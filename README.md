## <img src="https://cdn.simpleicons.org/rocket/8B0000" width="22" valign="middle"/> &nbsp;Sobre PROSEG

**PROSEG (Programa Servicios Generales)** es una plataforma institucional enfocada en la transformación digital y automatización de procesos internos, permitiendo una gestión más eficiente, escalable y centralizada de múltiples servicios operativos.

El sistema integra tecnologías modernas para facilitar:

| <img src="https://cdn.simpleicons.org/checkmarx/6DB33F" width="16"/> | Capacidad |
|---|---|
| <img src="https://cdn.simpleicons.org/googleanalytics/4285F4" width="16"/> | Gestión operativa institucional |
| <img src="https://cdn.simpleicons.org/adminer/4479A1" width="16"/> | Administración de recursos y procesos internos |
| <img src="https://cdn.simpleicons.org/keepassxc/8B0000" width="16"/> | Seguridad y control de acceso |
| <img src="https://cdn.simpleicons.org/apacheairflow/017CEE" width="16"/> | Integración entre servicios y módulos |
| <img src="https://cdn.simpleicons.org/zapier/FF4A00" width="16"/> | Automatización de flujos de trabajo |
| <img src="https://cdn.simpleicons.org/scaleway/4F0599" width="16"/> | Escalabilidad y mantenimiento independiente por servicio |

## <img src="https://cdn.simpleicons.org/diagramsdotnet/8B0000" width="22" valign="middle"/> &nbsp;Arquitectura

El proyecto sigue una arquitectura basada en **microservicios** dentro de un enfoque **monorepo**, permitiendo mantener una integración centralizada sin perder independencia entre módulos.

```bash
apps/       → Aplicaciones principales
services/   → Microservicios e infraestructura
```
